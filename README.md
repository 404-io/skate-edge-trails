# Skate Edge Trails

ローカル動画からスケーターの左右の足先を追跡し、ホッケーリンクを基準にしたメートル座標の軌跡へ変換するPWAです。動画はブラウザ内だけで処理します。

## 現在の機能

- MediaPipe Pose Landmarkerによる左右のつま先・かかと・足首の追跡
- 固定カメラと移動カメラ（リンクライン補正）の選択
- 動画内の赤線・青線の候補検出
- 動画候補をリンク図上のゴールライン／ブルーライン／センターラインへ手動で割り当て
- IIHF 60×30m、60×26mのリンク座標を基準にした射影変換
- 校正済みリンクの赤線・青線を動画フレームへ逆射影して重ね表示
- 移動カメラでは4つの基準点をフレームごとに追跡し、各フレームの射影変換で足先軌跡を補正
- 左右足の軌跡をリンク座標（m）で描画し、AR用JSONを出力
- 課題テンプレートと確認済みエッジラベルのデータセット出力

## 使い方

1. 動画とリンク規格を選びます。
2. 撮影方法を選びます。手持ち・パン撮影なら「移動カメラ（リンクライン補正）」を選びます。
3. 校正方法を選びます。
   - リンク外周が映る場合：動画上で左奥→右奥→右手前→左手前の順に4点をタップします。
   - 赤線・青線だけがよく見える場合：「動画のラインを検出」を押し、候補を選んでリンク図の同じ色の実ライン名へ割り当てます。正しい2本を「射影補正」として選び、「選んだ2本をリンク座標へ配置」を押します。
4. 動画上の薄い赤線・青線が、実際のリンクラインと重なることを確認します。ずれる場合は、別の明瞭なフレームでやり直します。
5. 「補正して軌跡を作る」を押します。
6. 補正率を確認して、`JSONを書き出す`でAR用の座標データを保存します。

## 補正の仕組み

氷面は平面なので、動画上の点 `p` とリンク上のメートル座標 `P` の対応から、フレームごとの射影変換 `P = H_t p` を計算できます。足先はこの変換でリンク座標へ戻し、ホッケーラインやARガイドは逆変換 `p = H_t^-1 P` で動画へ描きます。

移動カメラでは、基準フレームで選んだ4点を小さな画像テンプレートとして追跡し、各フレームの `H_t` を更新します。追跡できないフレームは誤った座標を混ぜないため、軌跡から除外します。

2本のラインによる自動校正は、候補の両端がボードとの交点に近い場合に使います。途中で途切れた線や、スケーター・反射で隠れた線では物理的な縮尺が正しくならないため、外周4点の手動校正を使ってください。

## 制約

- 射影変換は氷面上の点に有効です。足先・ブレード接地点の補正には使えますが、上半身の3D位置には使えません。
- 広角レンズの歪み、強い反射、急なカメラ移動、遮蔽は精度を下げます。
- 単眼動画だけではブレードのロール角を直接測れないため、イン／アウトは自動確定しません。確認済み動画ラベルをデータセット化して、将来の分類器学習へ利用します。
