# Skate Edge Trails

動画に映るスケーターの左右の足先を追跡し、ホッケーラインを基準にした実寸の軌跡パターンを作るPWAです。

## 現在の機能

- ローカル動画をブラウザで解析（動画をサーバーへ送らない）
- MediaPipe Pose Landmarkerで左右のつま先・かかと・足首を追跡
- ホッケーラインの既知長方形を4点指定し、画面座標をリンク上のメートル座標に射影変換
- 固定カメラと、リンクライン基準の移動カメラ補正を選択可能
- 移動カメラ時は、指定した4つのライン交点をフレームごとに追跡し、パン・回転・ズーム・遠近変化をリンク平面上で補正
- ライン追跡に失敗したフレームを軌跡から除外し、補正できたフレーム数を表示
- 左右足の軌跡をSVGで描画
- ブレード方向と進行方向から前進／後進（F/B）を推定
- 将来のUnity ARビューアで読み込める`skate-pattern.json`を出力

## 使い方

1. 動画を選びます。
2. 撮影方法で、三脚などの動画は「固定カメラ」、手持ち・パン撮影は「移動カメラ（リンクライン補正）」を選びます。
3. 動画上で、既知サイズのホッケーライン長方形を左奥→右奥→右手前→左手前の順にタップします。
4. 移動カメラでは、解析を始めたい時点で4点を選びます。4点ともライン交点が見え、スケーターに隠れないフレームを選んでください。この時点以降を解析します。
5. 幅・奥行の実寸を入力して「補正して軌跡を作る」を押します。
6. 補正率を確認し、`JSONを書き出す`でAR用の座標データを保存します。

## 補正の仕組みと制約

氷面は平面なので、同じリンク上の4点が各フレームでどこに映るかを使えば、動画座標からリンク座標への射影変換（ホモグラフィ）を作れます。カメラが動いてもこの変換を毎フレーム更新するため、カメラ自体の移動を足軌跡から分離できます。

ライン交点の近くに強い反射、同じ模様、長い遮蔽、または急激なカメラ移動があると追跡が不安定になります。そのフレームは意図的に除外します。補正率が低い場合は、より大きく明瞭なライン交点を4つ選び、カメラ移動が連続する短めの動画で試してください。

## 意図的に未確定にしていること

単眼動画ではブレードのロール角を直接測れないため、イン／アウト（I/O）を推測で確定しません。初期版では`F`／`B`だけを推定し、I/O判定は次段階で2台撮影またはブーツIMU、教師データによる分類器を導入してから扱います。

## 開発

```bash
pnpm install
pnpm dev
```

## 次の実装

1. ホッケーの赤線・青線・フェイスオフスポットの自動候補検出と手動補正
2. 軌跡の編集、SVG／PNG出力、共有URL
3. 2台動画またはIMUを使ったI/Oエッジ分類
4. Unity AR Foundationで、`skate-pattern.json`をAndroid / iOSの床へ配置
